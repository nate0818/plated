# Plated homepage

The `MarketingHome` component renders `/`. `/direction` remains an unlisted,
noindex alias for design review. The shared public-page system is documented in
`docs/website-system-2026-10-18.md` at the repository root.

- Selecting a cooking night updates the real app capture and pauses autoplay.
- Play resumes the preview; motion stops offscreen, in background tabs, with
  reduced motion, and with Save Data. The Table conversation is illustrative.
- FAQ panels animate their natural height, including when closed. Fine-pointer
  wheel and trackpad scrolling ease through Lenis; touch and keyboard scrolling
  stay native. Reduced motion disables the scroll engine and decorative depth.
- The App Store badge uses the existing unmodified Apple asset and coming-soon
  status. The working conversion path remains the early-access request form.
