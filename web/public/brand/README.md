# Website identity assets

`plated-mark.png` is copied without alteration from the approved native asset
`Plated/Assets.xcassets/AppIcon.appiconset/AppIcon.png`. The artwork script resizes
it for browser and touch icons. The masthead, footer and social card use the
Newsreader wordmark alone. The master remains in the native asset catalog.

`app-store-badge.svg` is Apple's unmodified black English badge, downloaded from
its badge service:
https://tools.applemediaservices.com/api/badges/download-on-the-app-store/black/en-us?size=250x83&releaseDate=1735689600

The configured listing returned HTTP 404 on October 16, 2026. The website places
the badge beneath an explicit coming-soon label and does not link it until the
listing is available. The working early-access action remains TestFlight.
