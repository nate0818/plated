# Editorial website photography

`shared-table.webp` is brand photography generated with the built-in image
generation tool for the October 16, 2026 homepage redesign. It is not an app
capture or a customer photograph. The original image and full generation
prompt are preserved in `docs/website-art-direction-2026-10-16/`.
It is retained from that exploration and is not used on the current homepage.

`salmon.webp`, `pizza.webp`, `poke.webp`, and `pancakes.webp` are optimized
versions of the existing demonstration food photographs in `design/`. The current
homepage uses salmon, pizza and pancakes as a conceptual personal recipe
collection. The images do not imply that recipes come preloaded with Plated.

`skewers.webp`, `rainbow.webp`, and `steak.webp` were converted from
`design/skewers.jpg`, `design/veggie.jpg`, and `design/plates.jpg` for an earlier
gallery. Those counter-flowing rows have been removed from the current homepage.

Product UI always comes from real app captures in `public/app/`.
