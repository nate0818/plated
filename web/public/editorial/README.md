# Editorial website photography

`shared-table.webp` is brand photography generated with the built-in image
generation tool for the October 16, 2026 homepage redesign. It is not an app
capture or a customer photograph. The original image and full generation
prompt are preserved in `docs/website-art-direction-2026-10-16/`.

`salmon.webp`, `pizza.webp`, `poke.webp`, and `pancakes.webp` are optimized
versions of the existing sample-recipe photographs in `design/`. Names and
total times are based on `Plated/Support/SampleData.swift`. They illustrate
the sample cookbook, not a claim about a recipe subscription or catalog.

Product UI always comes from the real app captures in `public/app/`.
