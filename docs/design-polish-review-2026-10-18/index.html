ONE COHERENT SYSTEM

Less searching.
More knowing.

01 / Clear priority

One visual anchor per view. A compact title, useful content, and the next action in that order.

02 / Familiar actions

Hearts for reactions, a gear for settings, overflow for secondary actions. Brand character belongs in typography, color, photography, and voice.

03 / Honest feedback

Suggested is different from assigned. Sending is different from sent. Read is different from cleared. Show those differences.

04 / Useful density

Keep related content close. Remove empty ceremony; preserve breathing room around decisions. Use space to clarify, not merely fill it.

05 / Calm consistency

Shared 8-point spacing rhythm, restrained borders, consistent icon weight, bounded photos, and readable supporting text.

06 / Accessible by design

Target at least 44-point controls, visible focus, meaningful labels, contrast checks, Dynamic Type reflow, and reduced-motion behavior. Native validation remains required.

Reference lens: Jon Yablonski · Laws of UX · Apple HIG

Proximity, hierarchy, familiar conventions, progressive disclosure, and visible system status guide the proposals. No guideline can guarantee a bug-free product.
